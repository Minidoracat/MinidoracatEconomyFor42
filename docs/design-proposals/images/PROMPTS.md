# 設計視覺稿 GPT-Image-2 Prompt 集

- 用途：把 `docs/economy-design-proposals.md` 的推薦組合畫成可討論的視覺稿（UI mockup、遊戲內場景、架構圖）。
- 產生方式：Codex 內建 `image_gen`（gpt-image-2）；每個 prompt 各生成一張，尺寸 2048x1152（16:9）。
- 風格庫範本：`ui-screenshot-system`（圖 1、2、3、5；參考 case 17、2、4）、`infographic-engine`（圖 4；參考 case 334、1、8）。
- 共同約束：畫面文字一律繁體中文、逐字正確、清晰可讀；數字半形；不得出現英文替代字、亂碼、浮水印、真實品牌 logo；不模仿任何既有 Workshop MOD 的黑市／骨頭／購物車視覺。這些圖是討論用視覺稿，不是最終 UI 規格。
